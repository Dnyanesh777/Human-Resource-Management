# Human Resource Management System

This is a Java-based desktop application developed using **NetBeans IDE** for managing employee-related operations in an organization. The application uses **Swing GUI**, image assets, and JDBC connectivity.

---

## 📁 Project Structure

```
Human-Resource-Management/
├── build/classes/
│   ├── db/
│   ├── guipages/
│   ├── humanresourcemanagement/
│   └── images/
├── nbproject/
├── src/
│   ├── db/
│   │   └── dbconnect.java
│   ├── guipages/
│   │   └── *.java (GUI files like login, dashboard, etc.)
│   ├── humanresourcemanagement/
│   │   └── HumanResourceManagement.java (main class)
│   └── images/
│       └── *.png / *.jpg (used in GUI)
└── README.md
```

---

## ✨ Features

- User authentication with login screen
- Graphical interface using Java Swing
- Employee data management (add/edit/view)
- Department & role assignment
- Attendance or loading screen (visual feedback)
- Image-based GUI elements for better UX

---

## 🛠️ Technologies Used

- **Java SE**
- **Swing** for GUI
- **JDBC** for database connectivity
- **MySQL** (or other JDBC-compatible DB)
- **NetBeans IDE**

---

## ⚙️ How to Run the Project

1. **Clone the repository:**

```bash
git clone https://github.com/Dnyanesh777/Human-Resource-Management.git
cd Human-Resource-Management
```

2. **Open the project in NetBeans:**
   - File → Open Project → Select this directory.

3. **Setup database (if used):**
   - Ensure MySQL is installed and database is created as expected by `dbconnect.java`.

4. **Run the project:**
   - Locate `HumanResourceManagement.java` in `src/humanresourcemanagement/` and run it.
